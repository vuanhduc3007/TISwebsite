# TIS website images — extracted from Company Profile

Pulled from `Profile_TIS__file_xem_online_.pdf` and cleaned up (color-corrected, transparency
fixed where the PDF used a mask). Organized into 4 folders:

## project-photos/ (19 images) — safe to use, these are TIS's own work
Real jobsite photos: Chợ Kim Tân, Chợ Trung Tâm Huyện Thuận Thành, Chợ Đầu Mối Ngã Tư Dâu —
building exteriors, crane/rooftop installs, panel close-ups, the electrical panel hookup, and
the delivery truck. Filenames tell you what's in them, but I matched most of these by visual
context rather than an explicit caption in the PDF (only the Thuận Thành and Ngã Tư Dâu
buildings have readable signage) — **double-check project attribution before publishing a
caption that names a specific client/site.** Good source material for a project gallery,
case-study pages, or homepage proof-of-work section.

## product-images/ (14 images) — usable, but low-res
Inverter and BESS unit product shots, background-cleaned. These are small (the PDF itself only
embeds them at brochure resolution — max ~250px on the long edge for most), so they'll look soft
above thumbnail size. For a product/brands page, it's worth pulling fresh hi-res shots from each
manufacturer's official press kit instead (Solis, Growatt, SolarEdge, Huawei, GoodWe, Deye,
Fronius, Sungrow, Jinko) rather than upscaling these.

## partner-logos/ (9 of the 12 profile logos) — same caveat as above
Transparent PNGs for MaxGE, CyberPower, Solis, LuxPower, Deye, JinkoSolar, JA Solar, Huawei, GCL.
Missing EVE, Fronius, and SMA — not embedded as separate logo images in the PDF page I pulled
from. Same resolution caveat as product-images: fine for a small partner-logo strip, worth
sourcing official brand-kit SVGs/PNGs if you want them any larger.

## decorative-stock-CHECK-LICENSE/ (12 images)
The generic corporate stock photography used for hero banners and section backgrounds (aerial
solar farm, engineers-in-a-field, double-exposure portraits, meeting-room silhouette, etc.).
**These are very likely licensed stock images (Freepik/Shutterstock-style), not TIS's own
photography** — the design brochure probably licensed them for that one document, and that
license may not cover republishing on a public website. Confirm the original license (or buy a
web-use license / swap for royalty-free alternatives) before putting these live. I've kept them
separate from `project-photos/` for exactly this reason.
